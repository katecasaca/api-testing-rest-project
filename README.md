# REST API Testing — QA Project

QA portfolio project focused on REST API testing, request validation, HTTP status codes and defect identification.

This project was completed as part of my QA Engineering training at TripleTen and demonstrates practical experience in designing and executing API test scenarios.

## Project Scope

The testing covered:

- REST API endpoints
- Positive and negative scenarios
- Request body validation
- Path parameter validation
- HTTP methods
- HTTP status codes
- Boundary values
- Missing and invalid data
- Business rule validation
- Defect identification

## Test Scenarios

The project included scenarios such as:

- Creating resources with valid data
- Validating required fields
- Testing duplicated values
- Testing minimum and maximum field lengths
- Testing invalid characters and input formats
- Testing empty and missing fields
- Deleting resources using valid and invalid IDs
- Validating API behaviour against expected requirements

## HTTP Response Validation

I validated API responses including:

- 200 OK
- 201 Created
- 400 Bad Request
- 404 Not Found
- 409 Conflict
- 500 Internal Server Error

## Bug Reporting

Failed API scenarios were documented and linked to defect reports.

The bug reports included:

- Test scenario
- Request data
- Expected result
- Actual result
- HTTP response
- Reproduction details
- Defect reference
